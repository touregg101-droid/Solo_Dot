# SOLO DOT

혼자 여행하는 사람들의 존재를 정확한 위치나 신원 공개 없이 도트로 느끼는 인터랙티브 프로토타입입니다.

## 기능

- 여행 도시와 기간 등록
- 6종 도트 아바타 선택
- 공개 지형 데이터를 단순화한 도시별 지도
- 하루 한 번 생존신고
- 익명 이모지 반응
- 여행 종료 카드 저장

## 실행

```bash
npm install
npm run dev
```

## 지도 데이터

도시 지도는 공개 도메인인 [Natural Earth](https://www.naturalearthdata.com/) 데이터를 단순화해 만들었습니다. 위치 추적이나 실제 사용자 GPS 좌표는 사용하지 않습니다.
